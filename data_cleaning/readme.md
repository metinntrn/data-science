# 🧹 Data Cleaning Projects

A collection of Python-based data cleaning and preprocessing projects built to simulate real-world data engineering and data science workflows.

These projects focus on transforming raw, inconsistent datasets into clean, analysis-ready data through modular, reusable pipelines.

---

## 🚀 Repository Goals

This repository demonstrates practical experience in:

- Data Cleaning
- Data Profiling
- Missing Value Handling
- Duplicate Detection & Removal
- Data Type Standardization
- Categorical Data Cleaning
- Time-Series Processing
- Automated Markdown Reporting
- Exporting Clean Datasets

---

## 📂 Projects

| Project | Description |
|----------|-------------|
| **E-CommerceData Cleaning** | Cleans transactional e-commerce data by handling missing values, duplicate records, incorrect data types, and canceled transactions. |
| **YouTubeRecommendation_data_cleaning** | Cleans noisy YouTube recommendation data by fixing categorical inconsistencies, mixed data types, timestamp formats, logical anomalies, and generating dataset profile reports. |
| **retail-data-cleaning** | Performs automated data profiling, missing value treatment, data type conversion, and preprocessing for a retail dataset. |

## 🔄 Common Pipeline Workflow

Most projects follow a modular pipeline:

1. Load Dataset
2. Generate Dataset Profile
3. Handle Missing Values
4. Remove Duplicates
5. Standardize Data Types
6. Clean Inconsistent Values
7. Handle Time-Series Data (if applicable)
8. Export Clean Dataset
9. Generate Markdown Report

---

## 📊 Output

Depending on the project, the pipeline generates:

- Cleaned CSV dataset
- Markdown profiling report
- Console logs
- Standardized analysis-ready data
